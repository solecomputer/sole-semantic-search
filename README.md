# SOLE Semantic Search

SOLE Semantic Search replaces native WordPress search with semantic search through SOLE Engine. Instead of matching exact words, it uses the meaning of each query to return the most relevant results.

- Replaces native WordPress search without changing how visitors search the site.
- Supports 1–50 results per page.
- Falls back silently to native WordPress search if SOLE Engine is unavailable.
- Shows an admin notice if SOLE Engine is missing while native search continues to work.
- Automatically translates the plugin interface when the site language is not English.

## Requirements

- WordPress 6.5 or later.
- PHP 8.3 or later.
- The SOLE Engine plugin installed and active.
- Semantic search enabled in the SOLE Engine settings.

## Install

Install SOLE Semantic Search from the [WordPress.org plugin directory](https://wordpress.org/plugins/sole-semantic-search/).

This repository is a read-only mirror of released versions. It is not the install source.

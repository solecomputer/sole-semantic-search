Replace native WordPress search with AI-powered semantic search via SOLE Engine.

== Description ==

SOLE Semantic Search replaces the default WordPress keyword search with semantic search powered by SOLE Engine. Instead of matching exact words, it understands the meaning behind search queries and returns the most relevant results.

**Features:**

* Seamless replacement of native WordPress search
* Configurable results per page (1-50)
* Automatic fallback to native search if SOLE Engine is unavailable
* Auto-translation of plugin UI when site language is non-English

**Requirements:**

* [SOLE Engine](https://wordpress.org/plugins/sole-engine/) plugin must be installed and active
* Semantic search must be enabled in SOLE Engine settings

= External services =

This plugin does not contact any external service directly. It performs its
searches through the required SOLE Engine plugin, which sends data to the SOLE
Engine service operated by Sole Computer (https://sole.computer) at
`engine.sole.computer`.

SOLE Engine requires a Sole Computer account and Engine User Key. If the key
is missing, this plugin makes no Engine request and native WordPress search
remains in use. If SOLE Engine rejects the key, native search remains in use;
an administrator must reconnect or replace the key in SOLE Engine settings.

**What reaches the service because of this plugin.** When a visitor runs a
search, the search query is sent so that it can be matched semantically against
your indexed content. Your posts and pages reach the service as indexed content
through SOLE Engine itself, not through this plugin.

**When.** On a visitor search, and when this plugin's own interface strings are
auto-translated on a non-English site. Installing or activating this plugin
sends nothing.

Because all traffic goes through SOLE Engine, its own disclosure — including
the background jobs it schedules — applies here too. See the SOLE Engine plugin
page for the full description.

== Installation ==

1. Install and activate the [SOLE Engine](https://wordpress.org/plugins/sole-engine/) plugin.
2. Enable semantic search in SOLE Engine settings.
3. Install and activate SOLE Semantic Search.
4. Visit Settings > SOLE Semantic Search to configure options.

== Frequently Asked Questions ==

= What happens if SOLE Engine is not installed? =

The plugin will display an admin notice asking you to install SOLE Engine. Native WordPress search continues to work normally.

= What happens if the semantic search fails? =

The plugin silently falls back to native WordPress search. No error is shown to visitors.

= Does this work with custom post types? =

The plugin intercepts the main search query. Results depend on what SOLE Engine has indexed.
